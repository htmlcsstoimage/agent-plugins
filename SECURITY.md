# Security Policy

## Supported versions

Security fixes are applied to the latest version of the plugin on the default branch.

## Report a vulnerability

Please report suspected vulnerabilities privately to [support@htmlcsstoimage.com](mailto:support@htmlcsstoimage.com) with the subject `Agent plugin security report`.

Include the affected file or component, reproduction steps, potential impact, and any suggested remediation. Please do not disclose the issue publicly until we have had an opportunity to investigate and address it.

For vulnerabilities in the hosted HTML/CSS to Image service rather than this plugin package, use the same private reporting address.
